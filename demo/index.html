Ten Protons Datepicker

Zero-dependency · accessible · Vanilla TS + Web Component

Emulated backend response

Paste a date string here as if it came from an API, to test how the pickers below parse and display it. One date (2025-03-15, 15.03.2025, Mar 15, 2025, or a Unix timestamp in seconds such as 1794072736) updates every single picker; two dates (2025-03-10, 2025-03-20) update every range picker; any number of dates updates every multiple picker. dd.mm.yyyy and dd/mm/yyyy are read day-first.

Single date

Click the field, or focus it and press ↓. In the calendar use arrows, PageUp/PageDown (Shift = year), Home/End, Enter, Esc.

Range

Click a start, then an end – hover to preview. Esc mid-pick keeps the previous range.

Multiple dates

Each click toggles a day; the calendar stays open. Click outside to close.

Date & time

enableTime adds a 24-hour hours : minutes : seconds selector below the calendar (the popup stays open so you can set it). Type 15/03/2025 13:07:09, 2025-03-15T13:07 or paste a timestamp. In a range one time applies to both ends.

Inline

Always visible. Use the buttons to change mode on the same instance.

Locales

Month and weekday names, first day of the week, default input format and text direction all come from Intl. Ukrainian also has translated UI strings; the other locales use the English ones.

Manual entry

Type a date and press Enter or leave the field. Separators are matched leniently (try 5/3/2025 with dd.MM.yyyy), ISO is always accepted, and dates outside min/max or on disabled days are rejected: Enter marks the field invalid, blur restores the last valid value. Allowed range here: 2025-01-01 … 2026-12-31, no Sundays.
